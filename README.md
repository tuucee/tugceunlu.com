# tugceunlu.com — Design Playground

This is an early visual playground for Tuğçe Ünlü's personal blog.

It intentionally uses the **same content in six different visual directions** so the design can be compared without changing the editorial idea.

## Themes

1. Literary Journal
2. Research Notebook
3. Forest After Rain
4. European Editorial
5. Midnight Notes
6. Playful Scientific

Use the theme buttons at the top of the page to switch.

## Files

- `index.html` — homepage prototype
- `styles.css` — all six visual directions
- `script.js` — theme switching
- `README.md` — this file

## Run locally

Double-click `index.html`, or use a local server such as VS Code Live Server.

## Publish with GitHub Pages

In the GitHub repository:

1. Open **Settings**
2. Go to **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Select branch `main`
5. Select folder `/ (root)`
6. Save

Once GitHub finishes deploying, the site will be available from the Pages URL shown in the same settings screen.

## This is not the final website

The point of this version is to answer:

- Which direction feels most like Tuğçe?
- Which is easiest to read?
- Which supports essays, science writing and projects equally well?
- Which parts should be mixed together?

After choosing a direction, the next version can add:
- real article pages
- project pages
- bilingual structure
- GitHub links
- newsletter / RSS
- custom domain
